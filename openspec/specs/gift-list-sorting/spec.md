# Capability: gift-list-sorting

## Purpose
TBD: Defines the sorting rules and behavior for the gift list.

## Requirements

### Requirement: Ordenação por disponibilidade
The system SHALL sort the gift list primarily by availability, where available items appear before unavailable items.

### Requirement: Ordenação secundária por preço
The system SHALL sort the gift list secondarily by price, so items with the same availability status are ordered according to their price.
